01 / ABOUT THE SERVER

造一座能让人
慢下来的世界。

大肥鱼是一个以原版生存为核心的 Minecraft 社区服。这里没有赶路的任务清单，只有想建就建、想玩就玩的轻松节奏。

无论你想在山谷搭一间小屋、研究红石与生电，还是找一群朋友分享日常，工坊都为你留了一盏灯。
